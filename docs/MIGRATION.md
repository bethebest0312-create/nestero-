Prisma migration & DB instructions

Overview

The repository schema.prisma was updated to add Site and TeamInvite models. Run the following steps locally to generate and apply migrations. It's recommended to run these in a development environment where your DATABASE_URL points to a dev Postgres instance.

Steps (recommended)

1. Install dependencies
   - npm ci

2. Generate Prisma client
   - npx prisma generate

3. Create & apply migration (interactive) - recommended
   - npx prisma migrate dev --name init

   This will:
   - Create a new migration folder under prisma/migrations
   - Apply the migration to your DATABASE_URL
   - Update node_modules/.prisma/client as needed

4. Non-interactive (create-only) — if you prefer to inspect SQL first
   - npx prisma migrate dev --create-only --name init
   - This leaves a migration SQL file under prisma/migrations/<timestamp>_init/
   - Inspect the generated SQL and then apply:
     - npx prisma migrate deploy

5. Seed
   - npm run seed

Notes about example SQL

Prisma will generate DB-specific SQL. Below is an example PostgreSQL snippet that approximates the required schema for review only. DO NOT run this blindly — prefer the SQL generated by prisma migrate.

-- Example (review only)
CREATE TABLE "Site" (
  "id" TEXT PRIMARY KEY,
  "slug" TEXT UNIQUE NOT NULL,
  "title" TEXT NOT NULL,
  "html" TEXT NOT NULL,
  "metadata" JSONB,
  "ownerId" TEXT,
  "createdAt" TIMESTAMP WITH TIME ZONE DEFAULT now(),
  "updatedAt" TIMESTAMP WITH TIME ZONE DEFAULT now()
);

CREATE TABLE "TeamInvite" (
  "id" TEXT PRIMARY KEY,
  "email" TEXT NOT NULL,
  "role" TEXT NOT NULL DEFAULT 'member',
  "token" TEXT UNIQUE NOT NULL,
  "accepted" BOOLEAN DEFAULT false,
  "createdAt" TIMESTAMP WITH TIME ZONE DEFAULT now(),
  "invitedById" TEXT
);

ALTER TABLE "Site" ADD CONSTRAINT "Site_ownerId_fkey" FOREIGN KEY ("ownerId") REFERENCES "User"(id) ON DELETE SET NULL;
ALTER TABLE "TeamInvite" ADD CONSTRAINT "TeamInvite_invitedById_fkey" FOREIGN KEY ("invitedById") REFERENCES "User"(id) ON DELETE SET NULL;

After applying migrations

- Run: npm run seed to create an admin user + optional demo Site and TeamInvite.
- Start dev server: npm run dev
